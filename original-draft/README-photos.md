# Lyk-Nu Website Images

Put your 7 gallery photos in this folder and name them:

- photo1.jpg
- photo2.jpg
- photo3.jpg
- photo4.jpg
- photo5.jpg
- photo6.jpg
- photo7.jpg

Then open `index.html` and replace each placeholder line like:

```html
<div class="gallery-placeholder">...</div>
```

with:

```html
<img src="images/photo1.jpg" alt="Photo 1" />
```

If your files are `.png`, use `.png` in the `src`.
